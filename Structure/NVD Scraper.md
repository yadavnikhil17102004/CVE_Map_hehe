# NVD Scraper (`nvd_scraper.go`)

> [!info] Purpose
> Enriches CVE data with details from the National Vulnerability Database (NVD) and CISA Known Exploited Vulnerabilities (KEV) catalog.

## 🔍 What it does
1. **Loads CVE → GitHub mapping files** (`data/YYYY.json`) generated by `cvemapping.go`.
2. **For each CVE**, queries the NVD API v2 (https://services.nvd.nist.gov/rest/json/cves/2.0) using an optional API key (`NVD_API_KEY`) for higher rate limits.
3. **Extracts fields** from the NVD response:
   - CVSS v2/v3 score, vector, severity
   - CWE IDs
   - Description, references
   - Publication / modification dates
4. **Checks CISA KEV feed** (https://www.cisa.gov/sites/default/files/food/known_exploited_vulnerabilities.json) to flag whether the CVE is actively exploited.
5. **(Optional) Pulls EPSS scores** if available via NVD or a separate EPSS endpoint (implementation dependent).
6. **Produces two outputs**:
   - Year‑scoped intel: `data/nvd_intel_YYYY.json` – a map keyed by CVE ID to the enriched object for that year (used by the frontend for faster loading).
   - Aggregate intel: `data/nvd_intel.json` – merge of all years (backward compatibility).
7. **Output schema** (example):
   ```json
   {
     "CVE-2024-1234": {
       "cveId": "CVE-2024-1234",
       "cvssScore": 9.8,
       "cvssVector": "CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H",
       "severity": "CRITICAL",
       "cwe": ["CWE-89"],
       "kev": true,
       "epss": 0.93,
       "description": "...",
       "references": [...]
     }
   }
   ```

## ⚙️ Workflow Diagram
```text
Start
  │
  ▼
[Read NVD_API_KEY from env/flag (optional)]
  │
  ▼
[Find all data/YYYY.json files in data/]
  │
  ▼
[For each year file:
   │
   ├─ Load CVE list
   │
   ├─ For each CVE:
   │    ├─ Call NVD API (with back‑off/retry)
   │    ├─ Parse JSON → extract CVSS, CWE, etc.
   │    ├─ Check CISA KEV JSON → set kev flag
   │    └─ (Optional) Fetch EPSS
   │
   └─ Build enriched map for the year]
  │
  ▼
[Write year‑scoped map to data/nvd_intel_YYYY.json]
  │
  ▼
[Merge all year maps → write data/nvd_intel.json]
  │
  ▼
End
```

## 📂 Related File
- **Source:** `nvd_scraper.go` (root of repository)
- **Inputs:** `data/YYYY.json` (from cvemapping)
- **Outputs:** 
  - `data/nvd_intel_YYYY.json` (per year)
  - `data/nvd_intel.json` (aggregate)

## 🛠️ How to Run Locally
```bash
go build nvd_scraper.go
./nvd_scraper -nvd-key="$NVD_API_KEY"
```
*(Flags: `-input-dir=data` to change where year files are read, `-output-dir=data` for where to write intel files.)*
