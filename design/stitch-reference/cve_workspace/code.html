NVD Technical Description

Improper Authentication in Apache HTTP Server 2.4.59 and earlier allows an attacker to bypass authentication requirements via a specially crafted request. The vulnerability exists in how the server handles certain encoded characters in the URL path, leading to a misinterpretation of the security policy applied to the resource. Successful exploitation can result in full administrative access to protected directories.
